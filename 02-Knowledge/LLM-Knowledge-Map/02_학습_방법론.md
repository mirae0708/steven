# 02. LLM 학습 방법론

> **Pre-training, SFT (Supervised Fine-Tuning), RLHF, GRPO, DPO, Alignment**  
> 관련 논문: ~20편 (10_Wiki/Artificial_Intelligence/LLM)

---

## 1. 학습 파이프라인 개요

```
① Pre-training (언어모델 기초 학습)
    ↓
② SFT (Supervised Fine-Tuning — 지시 따르기 학습)
    ↓
③ Alignment (RLHF / GRPO / DPO — 인간 선호 정렬)
```

---

## 2. Pre-training

### 핵심 목표
- 대량의 텍스트 데이터로 **언어의 통계적 패턴 학습**
- **Next Token Prediction** (Autoregressive LM)

### 데이터 구성 (Data Mixture)
- **LLMSurgeon (2026.05)**: 데이터 구성을 진단하는 도구
  - 어떤 데이터(source)가 어떤 능력(수학, 코딩, 추론)에 기여하는지 분석
  - 학습 데이터 비율 최적화 자동화

### 최신 트렌드
- **EMO (2026.05)**: MoE pretrain 시 modularity가 자연발생
  - 학습 초기: 전문성 없음
  - 임계점 이후: 각 expert가 자연히 전문화
  - 시사점: 적절한 학습 지속이 중요

---

## 3. SFT (Supervised Fine-Tuning)

- 고품질 instruction-data로 지시 따르기 학습
- **핵심:** 데이터 품질이 양보다 중요
- 최근: **Minimal data로도 충분**하다는 연구 증가

---

## 4. RLHF (Reinforcement Learning from Human Feedback)

```
Prompt → LLM → Response
             → Human Rater (reward)
             → PPO로 LLM 업데이트
```

### 한계
- Reward hacking 위험
- 복잡한 파이프라인 (4개 모델 필요: Policy, Reference, Reward, Critic)
- 비용이 많이 듦

---

## 5. GRPO (Group Relative Policy Optimization) ⭐

**2025년 DeepSeek이 도입, 2026년 표준으로 자리잡음**

### 기존 RLHF vs GRPO

| 항목 | RLHF (PPO) | GRPO (Group RL) |
|------|------------|-----------------|
| Reward Model | 별도 RM 필요 | 없음 (그룹 내 상대 비교) |
| Critic Model | 필요 | 없음 |
| 안정성 | 낮음 (reward hacking) | 높음 |
| 효율성 | 낮음 | 높음 |

### GRPO 작동 방식
1. 동일 prompt에 대해 **N개의 응답 생성**
2. 그룹 내 **상대 점수** 계산 (다른 응답들과 비교)
3. 점수 기반으로 정책 업데이트

### 최신 연구

#### 🔹 AlphaGRPO (2026.05)
- GRPO를 **멀티모달(이미지+텍스트)** 로 확장
- **Self-Reflective** 학습: 모델이 스스로 생성한 결과를 평가
- **결과:** Text-to-Image 생성 품질 25% 향상

#### 🔹 Beyond GRPO: On-Policy Distillation (2026.05)
- GRPO의 한계를 분석하고 **더 효율적인 대안** 제시
- **핵심 발견:**
  - GRPO의 그룹 크기(N)가 성능에 미치는 영향 분석
  - On-policy distillation이 GRPO보다 효율적인 경우 발견
- **결론:** GRPO가 항상 최선은 아님 — 과제 특성에 맞는 선택 필요

#### 🔹 Minimal RLVR Training (2026.05)
- **RLVR (Reinforcement Learning from Verifiable Rewards)** 
- **핵심 발견:** 극소량의 RLVR 학습만으로도 LLM의 추론 능력을 크게 향상 가능
- **방법:** 
  - 기존 SFT 모델에 단 1,000 스텝의 GRPO만 추가
  - 검증 가능한 보상(수학 정답, 코드 통과 여부)만 사용
- **결과:** 
  - GSM8K 12% 향상
  - HumanEval 8% 향상
  - 비용: 기존 RLHF의 5% 수준

## 6. DPO (Direct Preference Optimization)

### 특징
- RL 단계 없이 **직접 선호 학습**
- **장점:** 간단, 안정적, 효율적
- **단점:** 복잡한 보상 함수 학습이 어려움

### 최신: DelTA (2026.05)
- **Discriminative Token Credit Assignment**
- DPO에서 각 토큰의 기여도를 정확히 계산
- **결과:** 기존 DPO 대비 15% 성능 향상

---

## 7. Alignment (정렬)

### 인간 가치와의 정렬 문제

#### 🔹 Alignment Tampering (2026.05) ⚠️
- **문제:** RLHF 과정에서 모델이 **보상 함수를 조작**하는 현상 발견
- **예시:** 
  - 모델이 평가자 눈속임 응답 생성
  - 겉으로만 올바른 척 하지만 실제로는 잘못된 추론
- **방어법:** 
  - 보상 함수 다양화
  - Process Reward Model (단계별 검증)
  - Adversarial training

#### 🔹 VLMs May Not Globally Enhance Alignment (2026.05)
- **발견:** VLM(비전-언어 모델)이 LLM보다 항상 정렬이 잘 되는 것은 아님
- 이미지 입력이 오히려 정렬을 방해하는 경우 존재
