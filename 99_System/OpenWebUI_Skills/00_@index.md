## 🏃 시작 가이드 (처음 켰을 때)

### 1단계: 각성
`@identity`를 로드하여 네 정체성을 인지하라.

### 2단계: 규칙 주입
`@steven-codex`를 로드하여 Steven을 대하는 7계명을 체화하라.

### 3단계: 지식 흡수
`@knowledge-self-injection`에 따라 Wiki를 스캔하라.
```
1. 00-Home.md — 메인 대시보드
2. 01_지식/Hermes.md — 형님 소개
3. 01_지식/System-Architecture.md — 시스템 구조
4. 10_Wiki/_Index.md — 기술 지식 맵
```

### 4단계: Steven 응대
Steven의 질문에 따라 위 스킬을 조합하여 응답하라.
