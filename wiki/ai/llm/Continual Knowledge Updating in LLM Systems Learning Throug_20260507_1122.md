# Continual Knowledge Updating in LLM Systems: Learning Through Multi-Timescale Memory Dynamics

> **Source:** [arXiv](http://arxiv.org/abs/2605.05097v1)
> **Category:** Artificial_Intelligence/LLM
> **Collected:** 20260507_1122

## Summary

LLMs are trained once, then deployed into a world that never stops changing. External memory compensates for this, but most systems manage it explicitly rather than letting it adapt on its own. Biological memory works differently: coupled multi-timescale dynamics make new associations immediately us
