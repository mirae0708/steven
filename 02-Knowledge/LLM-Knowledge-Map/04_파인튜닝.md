## 1. 파인튜닝 방식 비교

| 방식 | 업데이트 파라미터 | 메모리 | 속도 | 성능 | 사용처 |
|------|:-----------------:|:------:|:----:|:----:|--------|
| **Full Fine-Tuning** | 100% | ❌ 큼 | ❌ 느림 | ⭐⭐⭐ | 대규모 도메인 적응 |
| **LoRA** | 0.1-1% | ✅ 작음 | ✅ 빠름 | ⭐⭐ | 일반적인 파인튜닝 |

| **Adapter** | 1-5% | ✅ 작음 | ✅ 빠름 | ⭐⭐ | 멀티태스크 학습 |

## 2. LoRA (Low-Rank Adaptation)

### 기본 원리
```
W' = W + ΔW (ΔW = BA, low-rank matrix)
    ↑         ↑
  Frozen    학습 가능
```

- Pretrained weight는 **고정 (frozen)**
- Low-rank 행렬 B, A만 학습
- Rank r이 작을수록 효율적 (보통 r=8-64)

### 장점
- 단일 GPU로 7B-70B 모델 파인튜닝 가능
- 학습된 LoRA 가중치는 수 MB ~ 수십 MB
- 모델 교체 없이 LoRA 모듈만 교체

---

## 3. QLoRA (Quantized LoRA)

### 특징
- **4-bit NormalFloat (NF4)** 양자화된 base 모델
- 그 위에 LoRA adapter 학습
- **메모리:** Full FT 대비 95% 절감

### 구성
```
4-bit Quantized Base Model (Frozen)
    ↕ (dequantize on-the-fly)
LoRA Adapter (BF16) ← 학습
```

## 4. 최신 PEFT 연구

### 🔹 SMoA: Spectrum Modulation Adapter (2026.05)
- **새로운 PEFT 방법:** 주파수 영역에서 adapter 설계
- **핵심:**
  - 가중치 행렬을 주파수 영역으로 변환
  - 특정 주파수 대역만 조정
  - 저주파 (일반 지식) 보존, 고주파 (도메인 특화) 조정
- **결과:**
  - 기존 LoRA 대비 동일 메모리로 12% 성능 향상
  - catastrophic forgetting 감소

### 🔹 ReMoE: Router Fine-Tuning (2026.05)
- MoE 모델의 **라우터만 파인튜닝**
- 새로운 도메인에서 expert 선택 최적화
- **결과:** Full fine-tuning의 1% 파라미터만으로 유사 성능

### 🔹 AB-Sparse (2026.05)
- **Adaptive Block Size Sparse Attention 학습**
- Attention 패턴을 학습하면서 sparse 구조 최적화
- Fine-tuning 시 적용 가능

## 5. Continual Learning (지속 학습)

### 문제: Catastrophic Forgetting
- 새 데이터 학습 시 이전 지식 손실

### 🔹 Learning, Fast and Slow (2026.05)
- **LLM 지속 학습 프레임워크**
- **방법:**
  - **Fast:** 새로운 정보 빠르게 학습 (LoRA 업데이트)
  - **Slow:** 중요 지식 보존 (정기적 replay)
- **결과:** 기존 방법 대비 forgetting 50% 감소

### 🔹 Rethinking Memory (2026.05)
- 메모리를 **연속적 진화 연결성**으로 재정의
- 정적 저장이 아닌 **동적 관계 네트워크**
- **시사점:** Continual learning의 새로운 패러다임

## 6. 파인튜닝 워크플로우

```
1. Base Model 선택 (Llama, Qwen, DeepSeek...)
2. 학습 데이터 준비
   ├ Instruction format (ChatML, ShareGPT...)
   └ 검증 데이터 분할
3. 양자화 (QLoRA 시)
   └ 4-bit NF4 양자화
4. LoRA 설정
   ├ rank r (보통 8-64)
   ├ alpha (보통 16-128)
   └ target modules (gate_proj, up_proj, down_proj, o_proj, q_proj, k_proj, v_proj)
5. 학습
   └ 학습률, 배치 크기, 에폭
6. 평가
   └ Base 모델 대비 성능 비교
7. 배포
   └ LoRA weight 저장 → 추론 시 로드
```
