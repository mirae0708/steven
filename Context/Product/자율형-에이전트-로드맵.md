# 자율형 AI 에이전트 로드맵

> 출처: [[01_지식/자율형-에이전트-로드맵]] (Members → Context 승격 완료)

## 비전: Hermes 자율형 에이전트 아키텍처
- 마크다운/텔레그램/Slack으로 명령 → AI Council 분석 → MCP Tool Router가 실행
- GitHub, Slack, AWS, 트레이딩 등 모든 도구를 MCP로 연결

## 핵심 발견 TOP 5

### 1️⃣ MCP (Model Context Protocol) — 25k⭐
모든 AI-외부도구 연결의 표준 프로토콜 (USB-C 같은 존재)
- JSON-RPC 2.0, STDIO/SSE/Streamable HTTP
- Hermes Gateway가 MCP 서버 역할 가능! (Python SDK)
- 모든 시스템 기능을 MCP 툴로 노출 → 다른 AI가 우리 기능 호출 가능

### 2️⃣ LangGraph — 12k+⭐
그래프 기반 에이전트 오케스트레이션 (상태 머신 + 조건부 분기)
- AI Council v4.0의 다음 단계: 단순 파이프라인 → LangGraph 그래프

### 3️⃣ Mastra — 5k+⭐
MCP 네이티브 + 도구 사용 + 메모리 올인원 TypeScript 프레임워크

### 4️⃣ MS Agent Framework — 10k+⭐
A2A(Agent-to-Agent) + MCP + 크로스랭귀지 차세대 멀티에이전트

### 5️⃣ OpenAI Agents SDK — 15k+⭐
컨테이너 안 자율적 코드 실행 + Sandbox Agent 개념

## 단계별 로드맵

| 단계 | 내용 | 난이도 |
|:----:|:-----|:------:|
| 🟢 Phase 1 | **Hermes MCP 서버 개발** — terminal/memory/file 노출 | 중 |
| 🟡 Phase 2 | **LangGraph 워크플로우** — 배틀루프를 그래프로 | 어려움 |
| 🟠 Phase 3 | **GitHub Actions 자동화** — Issue→AI→PR 파이프라인 | 쉬움 |
| 🔴 Phase 4 | **Slack/AWS MCP 연동** — 외부 시스템 통합 | 중 |
