# 🛃 통관 (Customs Clearance)

> 수출입 화물의 국가별 통관 규정 및 절차

## 한국 (Korea)

### 수출 통관
- **EDI 시스템** — 관세청 전자통관 (UNI-PASS)
- **필요 서류**: Invoice, Packing List, 원산지증명서, 수출신고서
- **HS Code** — 10자리 (6자리 WCO 기준 + 4자리 세번)
- **C/O (원산지증명서)** — FTA 활용 시 필수 (한-미, 한-EU, 한-중, 한-ASEAN 등)
- **선적 전 통관** — 세관장 확인 후 반출

### 수입 통관
- **수입신고** — 도착 전 예비신고(PCA) 가능
- **관세율** — HS Code 기준
- **부가세** — 10% (관세 포함 과세가격 기준)
- **보세구역 반입** — CY/CFS → 보세운송 → 통관
- **검사 비율** — 서류검사/검사면제 위주, 실물검사는 선별

## 주요 국가별 특징

### 미국 (USA)
- **CBP (Customs and Border Protection)** — ISF 10+2 규정 (선적 24시간 전 제출)
- **ACE (Automated Commercial Environment)** — 전자 통관 시스템
- **Customs Bond** — 수입자 의무 제출
- **FDA/USDA** — 식품/농산물 별도 규제
- **Section 301** — 중국산 관세 부과 품목 주의

### 중국 (China)
- **단일창구 (Single Window)** — 전자 통관 의무화
- **CCIC 검사** — 중고 기계 등 특정 품목 사전 검사
- **목록 통관** — 수입 화물 HS Code + 성분 정보 필수
- **VAT** — 13% 기본, 일부 9%
- **금지 품목** — 중고 의류, 특정 화학품 등

### EU (European Union)
- **ICS (Import Control System)** — 사전 적하목록 제출
- **EORI 번호** — 수입자 의무 등록
- **VAT** — 국가별 상이 (독일 19%, 네덜란드 21%, 프랑스 20%)
- **REACH** — 화학물질 사전 등록
- **CE Marking** — 전자/기계 제품 필수

### 일본 (Japan)
- **NACCS (Nippon Automated Cargo Clearance System)**
- **수입 허가제** — 식품/의약품/동식물
- **소비세** — 10%
- **원산지 심사** — FTA 협정세율 적용 시 엄격

### 베트남 (Vietnam)
- **VnACCS** — 전자 통관 시스템
- **사전 통관** — 선적 전 신고 가능
- **검사 분류** — Green/Yellow/Red Lane
- **Kicked Cargo** — 무작위 검사 대상

## 주의 사항

- **허위 신고** — 과태료/벌금/형사처벌 대상 (국가별 차이 있음)
- **금지 품목** — 마약/무기/위조품/멸종위기동물(CITES) 등 전 세계 금지
- **제한 품목** — 전자기기(KC/CE/FCC), 화학품(MSDS), 식품/의약품 각국 규제
- **Dangerous Goods** — IATA/IMDG Code 준수, MSDS 제출
