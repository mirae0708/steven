# To What Extent Does Agent-generated Code Require Maintenance? An Empirical Study

> **Source:** [arXiv](http://arxiv.org/abs/2605.06464v1)
> **Category:** Artificial_Intelligence/LLM
> **Collected:** 20260509_0421

## Summary

LLM 기반 코딩 에이전트가 생성한 코드의 유지보수성을 실증 연구. 100개 인기 리포지토리에서 1,000개 파일·3,200개 변경 분석 결과: (i) AI 생성 파일은 사람 코드보다 유지보수 빈도 낮음, (ii) AI 코드 수정은 기능 확장 위주 vs 사람은 버그 수정 위주, (iii) 유지보수의 대부분은 사람이 수행. → 코딩 에이전트의 코드 품질과 유지보수성에 중요한 시사점.
