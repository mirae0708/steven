# Prompt Engineering Knowledge — Community Patterns

**Source**: [f/prompts.chat](https://github.com/f/prompts.chat) — 161,722 ⭐

## Key Concepts

### What It Is
A community-driven platform for sharing, discovering, and collecting ChatGPT/LLM prompts. Self-hostable for privacy. Formerly "Awesome ChatGPT Prompts."

### Key Patterns for Hermes

1. **Community-Sourced Diversity**: Prompts from diverse use cases provide a rich pattern library
2. **Prompt Structures**: Common patterns: role-playing, chain-of-thought, constraint-based, format-specified
3. **Iterative Refinement**: Prompts evolve via community feedback — similar to Hermes' own self-evolution

### Prompt Categories to Reference
- **Role-based**: "Act as a [expert role]" patterns
- **Format-specified**: JSON, markdown, CSV output constraints
- **Multi-step**: Decomposed task instructions
- **Constraint-based**: Negative constraints ("do not mention X")

## Hermes Application
Use as a reference library for crafting effective prompts across diverse task types. When encountering a new task type, consult prompt patterns from this collection to find effective instruction templates.
