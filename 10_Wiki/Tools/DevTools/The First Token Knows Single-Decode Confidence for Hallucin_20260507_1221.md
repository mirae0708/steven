# The First Token Knows: Single-Decode Confidence for Hallucination Detection

> **Source:** [arXiv](http://arxiv.org/abs/2605.05166v1)
> **Category:** Tools/DevTools
> **Collected:** 20260507_1221

## Summary

Self-consistency detects hallucinations by generating multiple sampled answers to a question and measuring agreement, but this requires repeated decoding and can be sensitive to lexical variation. Semantic self-consistency improves this by clustering sampled answers by meaning using natural language
