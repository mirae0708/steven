## 🏆 추천: **n8n**

### 이유
1. **이미 설치 경험 있음** — WSL Docker로 설치 완료했었음
2. **워크플로우 + AI 노드** — LangChain 내장으로 AI 파이프라인 구축 가능
3. **400+ 통합** — Telegram, Email, DB, API 전부 지원
4. **자체호스팅 무료** — Community Edition으로 충분
5. **webhook 트리거** — Hermes API Gateway(:8642)와 연동 최적

### 우리 시스템 적용 예시

```mermaid
graph LR
    A[Invoice 도착] --> B{n8n Watch Folder}
    B --> C[invoice_auto 실행]
    C --> D{성공?}
    D -->|✅| E[Hermes Telegram 알림]
    D -->|🚨| F[FAILD 폴더 이동]
    F --> G[Hermes 긴급 알림]
    C --> H[DB 업데이트]
    H --> I[가상오피스 업무 할당]
```

### n8n 설치
```bash
docker run -d --restart always \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```
