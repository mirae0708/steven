# 보험 청구 프로세스

> 클레임 발생 시 보험 청구를 위한 단계별 가이드

## 1. 사고 발생 즉시

- [ ] 화물 상태 사진/비디오 촬영 (전체 샷 + 클로즈업)
- [ ] 컨테이너/포장 상태 기록
- [ ] 관계자(선사/항공사, 터미널)로부터 Incident Report 확보
- [ ] Seal Number 확인 및 사진

## 2. 24시간 이내

- [ ] 보험사 통지 (Policy No. 확인)
- [ ] Surveyor/Loss Adjuster 배정 요청
- [ ] 예비 손해액 산정
- [ ] 중고/폐기 여부 결정

## 3. 7일 이내

- [ ] 정식 Claim Form 제출
- [ ] 증빙 서류 패키지:
  - B/L or AWB 사본
  - Commercial Invoice & Packing List
  - Survey Report
  - 사진/비디오 증거
  - 손해액 산정 내역
- [ ] 선사/항공사에 Preliminary Claim 통지

## 4. 협상 및 정산

- [ ] 보험사 손해사정 결과 검토
- [ ] Salvage Value 협의
- [ ] 추가 증빙 요청 대응
- [ ] 최종 Settlement Agreement 서명

## 5. Recovery 추적

- [ ] Insurance Recovery 회수 확인
- [ ] Carrier Recovery (선사/항공사 책임분) 별도 청구
- [ ] Recovery Rate 기록 (KPI)

---

## 주요 보험 약관 확인 포인트

| 항목 | 확인 | 비고 |
|------|------|------|
| Coverage Type | All Risk / With Average / FPA | 전자부품은 All Risk 권장 |
| Franchise/Deductible | $500 or 1% | 초과분만 보상 |
| Time Limit | 30일 | Claim 통지 기한 |
| Survey Requirement | $5,000 이상 Survey 의무 | |
| Excluded Items | 취급 부주의, 자연 손실 | |
| Warehouse to Warehouse | 적용 여부 | Door-to-Door 커버리지 |
