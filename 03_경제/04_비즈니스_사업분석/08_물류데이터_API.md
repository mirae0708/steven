# 📊 물류 데이터 API (운임/스케줄)

> 국가별 THC/BAF/로컬운임 + 선사 스케줄 데이터를 API로 판매

## 💡 개요

`freight-local-cost-tavily-collector`로 수집한 각국 로컬운임 데이터 + `freight-schedule-rate-system`의 스케줄 데이터를 **API 상품화**.

## 🏗️ 보유 데이터

| 데이터셋 | 상태 |
|:---|:---|
| 국가별 로컬 운임 (THC, CUSTOMS, INLAND 등) | ✅ 수집 완료 |
| 4개 한국항구 스케줄 (인천/부산/평택/광양) | ✅ 구축 완료 |
| 선사별 월별 운임 | ✅ 업데이트 중 |
| Freight Quote 시뮬레이션 결과 | ✅ 수백건 보유 |

## 🎯 서비스

1. **운임 API** — 국가/품목/중량별 실시간 운임 조회
2. **스케줄 API** — 선사/항구/날짜별 선적 스케줄
3. **데이터 피드** — 매일 업데이트되는 CSV/Excel

## 📈 사업성

| 항목 | 내용 |
|:---|:---|
| **수요** | 포워딩사, 물류 스타트업, ERP 업체 |
| **경쟁** | Xeneta, Freightos (비싸고 복잡) |
| **차별점** | **한국/중국 중심** 저가 데이터 |
| **단가** | 월 10~50만원 또는 건당 과금 |
