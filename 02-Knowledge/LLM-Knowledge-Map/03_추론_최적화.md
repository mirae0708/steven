# 03. 추론 최적화

## 1. KV Cache (Key-Value Cache)

**Decoder-Only 모델의 핵심 최적화 기술**

### 기본 원리
- Self-attention에서 **이전 토큰의 Key, Value를 재사용**
- 매 generation 마다 전체 attention을 다시 계산하지 않음
- **효과:** 생성 속도 10-100배 향상

### KV Cache 메모리 문제
- 컨텍스트 길이 × 레이어 수 × 헤드 수 × hidden_dim
- 128K 컨텍스트에서 **수십 GB 필요**
- 특히 긴 컨텍스트에서 병목

### 최신 연구

#### 🔹 KVServe (2026.05)
- **Service-Aware KV Cache Compression**
- **핵심:** 서비스 특성에 맞춰 KV Cache를 압축
  - 지연 시간 민감 서비스: 적극적 압축 (품질 ↓, 속도 ↑)
  - 정확도 민감 서비스: 보수적 압축 (품질 유지)
- **방법:**
  - Attention score 기반 중요도 측정
  - 중요도 낮은 KV 쌍 선택적 제거
  - 통신 최적화 (분산 환경)
- **결과:** 메모리 사용량 60% 감소, 성능 저하 < 2%

#### 🔹 VideoMLA (2026.05)
- **Low-Rank Latent KV Cache** for Video Generation
- KV Cache를 저차원 잠재 공간에 압축
- **결과:** 1분 분량 비디오 생성 시 KV Cache 80% 감소

## 2. Speculative Decoding

### 원리
```
작은 모델(draft) → 빠르게 N개 토큰 생성
               → 큰 모델(target)이 한번에 검증
               → 맞으면 전부 accept → 1회 forward로 N토큔 생성
```

### 효과
- **지연 시간:** 2-3배 감소
- **품질:** 손실 없음 (Lossless)

### 최신: SpecKV (2026.05)
- **Adaptive Speculative Decoding with Compression-Aware KV**
- KV Cache 압축을 고려한 speculative decoding 최적화
- **결과:** 기간 대비 30% 추가 속도 향상

## 3. 양자화 (Quantization)

### 주요 방법

| 방법 | 비트 수 | 설명 | 성능 저하 |
|------|---------|------|:---------:|
| GPTQ | 4-bit | Weight-only 양자화 | 미미 |
| AWQ | 4-bit | 중요 채널 보호 양자화 | 매우 미미 |
| GGUF | 2-8 bit | CPU+GPU 혼용 양자화 | 2-bit에서 유의미 |
| NF4 | 4-bit | Normal Float, QLoRA용 | 미미 |

### 양자화 + KV Cache
- KV Cache도 양자화 가능 (INT8, FP8)
- **최신:** KVServe에서 KV Cache 압축과 양자화 결합

## 4. MoE 추론 최적화

MoE 모델은 모든 expert를 메모리에 로드해야 해서 메모리 요구량이 큼

### PALS (2026.05)
- **Power-Aware LLM Serving for Mixture-of-Experts Models**
- **핵심 아이디어:** 
  - 모든 expert를 항상 활성화할 필요 없음
  - 전력 소모와 성능의 균형점 찾기
- **방법:**
  - Expert 중요도 예측
  - 덜 중요한 expert는 저전력 모드
  - 중요 expert에 리소스 집중
- **결과:** 전력 소모 30% 감소, 지연 시간 유지

### TIDE (2026.05)
- **Efficient and Lossless MoE Diffusion LLM Inference**
- MoE Diffusion 모델의 손실 없는 추론 최적화
- **방법:** Expert 활성화 패턴 최적화

## 5. 추론 최적화 체크리스트

```
□ KV Cache 활성화
   └ 메모리 부족 시 → KVServe 스타일 중요도 기반 압축
□ Speculative Decoding 적용
   └ 작은 draft 모델 준비
□ 양자화
   └ 4-bit (GPTQ/AWQ) 우선 시도
   └ 필요시 GGUF 4-bit
□ MoE 모델 특화
   └ PALS 스타일 전력/성능 최적화
□ Batch Serving
   └ Continuous batching (vLLM)
   └ PagedAttention (vLLM)
```
