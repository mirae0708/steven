# 🚀 AI 물류 에이전트 SaaS

> 우리의 `invoice_auto` + `Hermes Agent` 기술을 SaaS로 상품화

## 💡 개요

물류 포워딩 회사들이 ERP에 인보이스를 수동 입력하는 대신, **AI가 PDF/Excel 인보이스를 자동 파싱 → 시스템에 직접 입력**해주는 B2B SaaS.

## 🏗️ 핵심 기술 (이미 보유)

| 기술 | 현재 상태 |
|:---|:---|
| OCR/AI 인보이스 파싱 | ✅ GLM-4.7-Flash + DeepSeek (운영중) |
| ERP 자동 입력 (Selenium) | ✅ SYS9005/SEA1002/AIR1002 (운영중) |
| 멀티모달 (해운/항공/특송) | ✅ SEA/AIR/EXPRESS 전부 대응 |
| 텔레그램 알림 | ✅ Hermes 연동 완료 |
| 멀티 LLM 라운드테이블 | ✅ 보유 |

## 🎯 타겟 고객

1. **중소 포워딩 회사** (ERP는 있는데 자동화 못함)
2. **중국 현지 포워딩** (MRCloud/SYS9005 사용사)
3. **해외 에이전트** (송장 처리량 많은 곳)

## 📈 사업성 분석

| 항목 | 분석 |
|:---|:---|
| **시장 규모** | 국내 포워딩사 2,000+개사, 월 5~50만원 = 연 12~120억 시장 |
| **경쟁사** | 없음 (OCR SaaS는 있지만 ERP 자동입력까지 하는 곳 없음) |
| **차별점** | 단순 OCR ❌ → AI 파싱 + **ERP 자동 입력** + **알림**까지 ✅ |
| **진입장벽** | 각 ERP별 커스터마이징 필요 (MRCloud 특화) |
| **수익모델** | 월 구독 (5~50만원/사) + HBL당 건당 과금 |
