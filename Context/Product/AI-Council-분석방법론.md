# AI Council — 분석 방법론

> 출처: [[01_지식/AI-Council]] (Members → Context 승격 완료)

## 개요
AI Council은 3명의 AI 분석가가 독립적으로 시장을 분석하고 다수결로 매매 결정을 내리는 시스템. 각 분석가는 서로 다른 관점과 도구를 사용하며, 최종 결정은 합의 또는 다수결로 이루어진다.

## 분석가 구성

### 📊 기술적 분석관 (Technical Analyst)
**역할**: 차트 패턴, 기술적 지표 기반 분석
**평가 기준**: 이동평균선(20/60/120일), RSI, 볼린저밴드, 거래량 추세, 지지/저항, MACD, Stochastic
**판단 스타일**: 보수적 — 추세 확인 후 진입

### 🔍 뉴스 모멘텀 분석관 (News Momentum Analyst)
**역할**: 뉴스 감성, 키워드 트렌드 기반 분석
**평가 기준**: 뉴스 헤드라인 감성, 업종별 모멘텀, 키워드 빈도, 시장 심리, 기업 공시
**판단 스타일**: 공격적 — 뉴스 모멘텀 포착 시 선제 대응

### 📉 리스크 관리관 (Risk Manager)
**역할**: 포트폴리오 리스크, 시장 환경 평가
**평가 기준**: CB Score, 포트폴리오 손익률, 종목별 비중 한도, 변동성, 상관관계 리스크, 환율/원자재
**판단 스타일**: 방어적 — 리스크 우선, 손절 규칙 엄격

## 의사결정 프로세스

### 1. 데이터 수집
- `market_intel.json` 로드, 각 분석가별 필요 데이터 추출, 포트폴리오 현황 로드

### 2. 독립 분석
```
[기술적 분석관] → BUY/SELL/HOLD + 근거
[뉴스 분석관]   → BUY/SELL/HOLD + 근거
[리스크 관리관]  → 포지션 사이즈 + 리스크 평가
```

### 3. 다수결 투표
| 투표 결과 | 결정 |
|:---------|:------|
| 3 BUY | 강력 매수 (CB 허용 범위 내 최대) |
| 2 BUY 1 HOLD | 매수 (중간 사이즈) |
| 2 BUY 1 SELL | 매수 (소형) |
| 모두 HOLD | 유지 |
| 2 SELL 이상 | 매도/포지션 축소 |

### 4. CB Score 기반 포지션 사이징
| CB Score | 포지션 사이즈 |
|:---------|:-------------|
| 0-20 (극단 공포) | 최대 20% |
| 20-40 (공포) | 최대 40% |
| 40-60 (중립) | 최대 60% |
| 60-80 (탐욕) | 최대 80% |
| 80-100 (극단 탐욕) | 최대 50% (과열 주의) |
