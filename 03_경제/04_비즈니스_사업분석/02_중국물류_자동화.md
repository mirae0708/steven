# 🇨🇳 중국-한국 물류 브릿지 자동화

> ✅ **Context 승격 완료** → [[Context/TechStack/물류-ERP-연동가이드]]
> 이 파일은 Members/ 원본입니다. 수정 시 Context 버전도 함께 업데이트하세요.

> 중국 사무실 + 한국 본사를 잇는 완전 자동화 물류 브릿지

## 💡 개요

중국 물류업체 발굴 → 이메일 마케팅 → 견적 → 계약 → 정기 화물까지 **전 과정 자동화**.

현재 `china_market_dev.py`로 중국 업체 DB와 메일 발송 자동화가 이미 되어있음.

## 🏗️ 보유 기술

| 기술 | 상태 |
|:---|:---|
| 중국 물류업체 DB | ✅ 100+ 업체 구축 |
| 중국 메일 자동 발송 | ✅ 운영중 |
| 중국 시장 보고서 | ✅ 주기적 생성 |
| GLM 중국어 특화 AI | ✅ Zhipu GLM-4.7-Flash (무료) |
| 중국어 OCR | ✅ 중국 인보이스 파싱 가능 |

## 🎯 서비스 구성

### 1️⃣ 중국 포워더 발굴 자동화
- 타오바오/1688/알리바바 → 물류업체 크롤링
- 자동 이메일 마케팅 (중국어)
- 관심 업체 → 자동 견적 요청
- 계약 → 정기 거래로 전환

### 2️⃣ 중국발 인보이스 자동 처리
- 중국 공급업체 인보이스 → AI 파싱
- 한국 ERP 자동 입력
- 양방향 물류 현황 대시보드
