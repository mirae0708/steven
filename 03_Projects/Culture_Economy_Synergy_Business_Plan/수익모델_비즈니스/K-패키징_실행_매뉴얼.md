# 🅰 K-패키징 — 이렇게 하면 돈이 됩니다

> "한국에서 K-푸드, K-뷰티, K-팝 굿즈를 한 번에 사서 해외로 보내주는 서비스"

---

## 1. 이게 뭔데?

쉽게 말하면 이겁니다:

**미국에 사는 김서방**이 한국 제품을 사고 싶다고 해봐요. 
- 신라면 큰 박스 하나
- 자기 여자친구가 좋아하는 K-뷰티 로션 3개
- BTS 굿즈 티셔츠 2장

지금은 이걸 각각 따로 배송시켜야 해서 배송비가 제품값보다 더 나와요.

**우리가 하는 일:**
- 이 모든 걸 **한 박스에 모아서** 
- **부산에서 LA까지 배로 보내고**
- **LA 창고에서 김서방 집으로 택배**

배송비 반으로 줄어들고, 김서방은 행복하고, 우리는 수수료 먹고, 선사(HMM 같은)는 화물 채워지고 — **4명 다 좋은 구조**

---

## 2. 준비물 — 뭐가 필요하냐

### 1단계: 물건을 줄 회사 (공급처) 20곳

| 종류 | 어디서 구하나 | 몇 곳 |
|-----|------------|------|
| K-푸드 (라면, 김치, 소스, 과자) | 농심, CJ제일제당, 대상, 오뚜기 — 수출팀에 전화 | 5곳 |
| K-뷰티 (로션, 팩, 선크림) | 아모레퍼시픽, LG생활건강 — 인디브랜드는 서울 성수동 | 10곳 |
| K-팝 굿즈 (티셔츠, 포카, 악세사리) | HYBE, SM, JYP — 굿즈 유통사 연락 | 5곳 |

> **방법은 간단합니다.** "저희가 해외 바이어 연결해드립니다. 물량 나가면 수수료 드릴게요" — 한국 회사들은 수출만 되면 다 OK

### 2단계: 물류 준비 — 너는 이미 다 있어

| 필요한 것 | 어떻게 | 상태 |
|---------|-------|------|
| 부산 창고/CFS | 부산항 배후단지 소형 창고 월세 | ⏳ 임대 필요 (월 100-200만원) |
| HMM/팬오션 선사 계약 | 부산↔LA FCL 주 1회 슬롯 | ✅ 네트워크 있음 |
| LA 현지 창고 | LA/LB 항만 인근 3PL 업체 계약 | ⏳ 알아봐야 함 |
| 미국내 택배 계약 | UPS/FedEx 비즈니스 계정 | ⏳ 개설 필요 |

### 3단계: 시스템 — 간단한 주문 페이지

- **필요한 기능**: 해외 바이어가 보고 → 고르고 → 결제 → 우리가 주문 취합 → 선적
- **비용**: PHP+MySQL 정도면 충분, 1-2주면 만듦
- **견적 시스템에 붙여도 됨** (있는 거 재활용)

## 3. 돈 버는 방법 — 이게 핵심

### 수익 구조 3가지

#### ① B2B: 해외 소매점에 납품 (80% 매출)

**어떻게:**
- 미국 LA 코리아타운 마트, H마트 같은 데 찾아가서
- "한국에서 K-푸드 + K-뷰티 + 굿즈 **한 번에 주문**해서 보내드립니다"
- "각각 따로 시키면 배송비 3번 내야 하는데, 저희는 한 번만 내면 됩니다"

**내가 버는 돈:**
```
예: LA 마트가 신라면 500박스 + 김치 200박스 주문
제품가: $10,000
우리 수수료 8%: $800
배송비 마진 10%: $400
━━━━━━━━━━━━━━━━━
한 건 순이익: $1,200
한 달 20건: $24,000
```

#### ② B2C: 해외 개인 팬 (15% 매출)

**어떻게:**
- "K-컬처 월간 구독 박스" — 매달 한국 인기 제품을 박스에 담아 보내줌
- K-팝 팬들이 좋아할 제품으로 구성

**내가 버는 돈:**
```
월 구독료: $50/명
제품원가: $25 (한국에서 직구)
배송비: $10 (물류 최적화)
━━━━━━━━━
순이익: $15/명/월
500명만 모아도: $7,500/월
```

#### ③ 긴급/맞춤 배송 (5% 매출)

**어떻게:**
- "에어 보내주세요" 하는 급한 주문
- 소량이지만 비싸게 받음

**내가 버는 돈:**
```
소형 박스 1개 항공특송: 배송비 $50
실제 비용: $30
━━━━━━━
순이익: $20/건
하루 3건: $60/일 = $1,800/월
```

## 4. 돈이 어떻게 흐르는지 — 숫자로 보여줌

### 월 1억 원 매출의 구조

```
한 달에 이런 일이 일어납니다:

1. B2B 고객 20개 매장
   - 매장당 평균 $2,000 주문
   - 총: $40,000 (약 5,500만 원)

2. B2C 구독 회원 500명
   - 월 $50 × 500명
   - 총: $25,000 (약 3,400만 원)

3. 긴급 배송 90건
   - 건당 $50
   - 총: $4,500 (약 600만 원)

━━━━━━━━━━━━━━━━━━━━━
한 달 총 매출: 약 $69,500 (약 1억 원)
```

### 비용 내역

| 항목 | 월 비용 | 비고 |
|-----|--------|------|
| 부산 소형 창고 | 150만 원 | 30평, CFS 겸용 |
| LA 3PL (보관+피킹) | $1,500 (200만 원) | 월 500박스 기준 |
| 시스템 유지비 | 50만 원 | 호스팅+도메인 |
| 직원 1명 (부산) | 300만 원 | 입고/검수/포장 |
| 마케팅 (구글/인스타) | $500 (70만 원) | |
| **총 월 비용** | **약 770만 원** | |

### 순수익

```
월 매출: 1억 원 (약 $69,500)
월 비용: 770만 원
━━━━━━━━━━━━━
월 순수익: 약 9,230만 원

1년이면: 약 11억 원
초기 투자 5,000만 원 → 1년 뒤 11억
ROI: 22배
```

## 5. 첫 6개월 — 뭐부터 해야 하냐

### Month 1: 전화부터 돌려라

| 주차 | 할 일 | 예상 결과물 |
|-----|------|-----------|
| 1주차 | 공급처 전화: 농심, CJ, 아모레, HYBE — "수출 협력 제안" | 3-5곳 OK 받기 |
| 2주차 | LA 바이어 리스트업: H마트 10개, 코리아타운 마트 20개 | 30개 타겟 리스트 |
| 3주차 | 부산 창고 알아보기: 항만 배후단지 30평 | 견적 3개 받기 |
| 4주차 | HMM/팬오션에 FCL 슬롯 문의 | 월 1회 부산↔LA 견적 |

**투자: 200만 원** (전기료, 교통비, 커피값)

### Month 2: 시스템 만들기

| 주차 | 할 일 |
|-----|------|
| 1-2주차 | 주문 페이지 제작 (제품 보여주고 → 고르고 → 카드 결제) |
| 3주차 | LA 3PL 계약 (보관료, 피킹비 협상) |
| 4주차 | 첫 바이어 방문: LA 마트 2-3곳 직접 만나기 |

**투자: 1,000만 원** (시스템 + LA 출장)

### Month 3: 첫 거래

| 주차 | 할 일 |
|-----|------|
| 1주차 | LA 바이어 1-2곳 첫 주문 받기 |
| 2주차 | 한국 공급처 → 부산 창고 입고 |
| 3주차 | 컨테이너 선적 (부산→LA) |
| 4주차 | LA 창고 도착 → 현지 택배 발송 |
| 📍 | **첫 고객 인도 완료!** |

### Month 4-6: 속도 붙이기

| 월 | 할 일 |
|---|------|
| 4월 | B2B 고객 5→15개로 확장 |
| 5월 | B2C 구독 박스 준비 (제품 구성, 가격, 마케팅) |
| 6월 | **BTS 컴백 시즌 맞춰 구독 박스 런칭!** |

## 6. 이렇게 하면 망한다 — 조심할 점

### 조심 1: 재고 사지 마라
- 처음에는 **주문 들어온 것만 산다**
- "선주문 후조달" — 위험 제로
- 재고 쌓이면 거기서 다 까먹음

### 조심 2: LA 창고 업체 잘 골라라
- 한국인이 하는 3PL 업체 찾아라
- "우리 잘합니다" 말고, **지금 한국 제품 얼마나 보관 중인지** 물어봐라
- 실적 없는 신생 업체는 걸러라

### 조심 3: 환율
- 달러 받고 원화 주면 환율 리스크 생김
- 해결: **계약서에 "달러 결제, 환율 변동시 재협상"** 넣어라

### 조심 4: 처음엔 1개 국가만
- 미국만. 끝.
- 미국에서 검증되고 → 일본 → 동남아 순서
- 처음부터 여러 나라 하면 물류 지옥

```
Q. 네가 할 수 있냐?
A. 이미 물류 인프라(견적 시스템, 선사 네트워크)가 있다.
   여기에 K-컬처 상품만 얹으면 된다.

Q. 언제부터?
A. 지금. 첫 전화는 오늘 돌려라.

Q. 1년 뒤?
A. 월 1억 이상. 재투자하면 3년 안에 연 100억도 가능하다.
```
