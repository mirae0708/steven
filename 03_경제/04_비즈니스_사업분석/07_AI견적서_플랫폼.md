# 🤖 AI 견적서 자동화 플랫폼

> Freight Quote Tool + AI = 1초 견적서 플랫폼

## 💡 개요

Freight Quote Tool이 이미 수백 건 시뮬레이션을 자동으로 돌릴 수 있음. 여기에 **AI 상담 챗봇 + 자동 견적 발송**을 더해서 **물류 견적서 SaaS**로 확장.

## 🏗️ 보유 기술

| 기술 | 상태 |
|:---|:---|
| Freight Quote Tool | ✅ SEA/AIR/EXPRESS 견적 자동 산출 |
| 시뮬레이션 200건 검증 | ✅ 완료 |
| Hermes 텔레그램 연동 | ✅ 가능 |
| 견적서 포맷 | ✅ 인코텀즈/THC/BAF 포함 |

## 🎯 서비스

1. **고객이 "한국→베트남 20ft 컨테이너 얼마?"** 라고 물으면
2. **AI가 요청 분석 → Quote Tool 호출 → 견적서 생성**
3. **자동 이메일/카톡 발송**
4. **고객 확인 → Booking 자동 전환**

## 📈 사업성

| 항목 | 내용 |
|:---|:---|
| **시장** | 국내 포워딩 2,000개사, 월 평균 견적 500건 |
| **시간 절감** | 1건 30분 → 1초 (99.9% 절감) |
| **단가** | 월 10~30만원 |
| **수요** | 영업팀 많은 회사일수록 수요 높음 |
