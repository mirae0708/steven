# RunAgent: Interpreting Natural-Language Plans with Constraint-Guided Execution



👤 Arunabh Srivastava, Mohammad A.,  Khojastepour

> Humans solve problems by executing targeted plans, yet large language models (LLMs) remain unreliable for structured workflow execution. We propose RunAgent, a multi-agent plan execution platform that interprets natural-language plans while enforcing stepwise execution through constraints and rubric

## Links
- 🔗 [Original](http://arxiv.org/abs/2605.00798v1)

## Key Takeaways
- **Multi-agent plan execution**: interprets NL plans, enforces stepwise constraints via agentic language (IF, GOTO, FORALL)
- **Dynamic tool selection**: chooses between LLM reasoning, code gen (Python), and tool usage per step
- **Context filtering**: retains only relevant info per step — prevents context pollution
- **Outperforms PlanGEN** on Natural-plan and SciBench datasets
- **Relevant to Hermes**: constraint-guided step execution pattern; dynamic tool selector architecture
