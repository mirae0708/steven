# ✈️ 항공운송 (Air Freight)

> 미래국제물류 기준 항공수출입 프로세스, 주요 항공사, 루트

## 프로세스

### 수출 (Export)
1. **Booking** — 항공사 or GSSA에 Space 예약
2. **Pickup** — Cargo 수거 → 인천공항 CFS 반입
3. **Export Customs** — 수출 통관 (EDI)
4. **Security Screening** — 항공 보안 검색
5. **Build-up** — ULD/Pallet 적재
6. **AWB 발행** — Master AWB (항공사) + House AWB (포워더)
7. **Flight Departure** — 출발 확인
8. **Pre-alert** — 도착지 에이전트에 사전 통보

### 수입 (Import)
1. **Arrival Notice** — 항공사 화물 도착 통보
2. **Customs Clearance** — 수입 통관
3. **Break-down** — ULD 분해, Cargo 인계
4. **Duty/Tax** — 관세/부가세 납부
5. **Local Delivery** — 최종 목적지 배송

## 주요 루트

- **미주**: ICN→LAX (11h) / ICN→ORD (13h) / ICN→JFK (14h) / ICN→ATL (14h)
- **유럽**: ICN→FRA (12h) / ICN→AMS (12h) / ICN→LHR (13h) / ICN→CDG (13h)
- **동남아**: ICN→BKK (5h) / ICN→SGN (5h) / ICN→SIN (7h) / ICN→MNL (4h)
- **중국**: ICN→PVG (2h) / ICN→PEK (2h) / ICN→CAN (3h)
- **일본**: ICN→NRT (2.5h) / ICN→KIX (2h)

## 요금 체계

| 항목 | 설명 |
|:-----|:------|
| **TACT Rate** | IATA 국제 항공운임 기준 |
| **Contract Rate** | 포워더/대량화물 할인 운임 |
| **Surcharge** | Fuel Surcharge, Security Fee, AWB Fee |
| **Minimum Charge** | 최소 청구 금액 (보통 $50~$150) |
| **GCR** | General Cargo Rate (일반 화물) |
| **SCR** | Specific Commodity Rate (특정 품목 할인) |
