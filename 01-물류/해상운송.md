# 🚢 해상운송 (Ocean Freight)

> 미래국제물류 기준 해상수출입 프로세스, 주요 선사, 운항 루트

## 프로세스

### 수출 (Export)
1. **Booking** — Shipper로부터 Booking Request 접수 → 선사에 S/I 제출
2. **Pickup / CFS** — CY(FCL) 또는 CFS(LCL)로 화물 반입
3. **Customs Decl.** — 수출 통관 진행
4. **VGM / Cut-off** — VGM 제출, CY 마감 준수
5. **Loading** — 선적, B/L 발행
6. **HBL 발행** → Forwarder B/L
7. **MBL 발행** → Master B/L (선사 발행)
8. **Documentation** — CI, PL, COO 등 서류 송부

### 수입 (Import)
1. **Arrival Notice** — 선사/대리점으로부터 도착 통보
2. **DO (Delivery Order)** — B/L 원본 or Telex Release → DO 교환
3. **Customs Clearance** — 수입 통관
4. **Duty/Tax Payment** — 관세/부가세 납부
5. **CY / CFS 반출** — 컨테이너 인수
6. **Local Delivery** — 최종 목적지 배송

## 주요 루트

### 원양 (Deep Sea)
- **미주 서안 (USWC)**: 부산→LA/Long Beach→Chicago/댈러스 (약 14일)
- **미주 동안 (USEC)**: 부산→뉴욕/사바나 (약 26일, 파나마 or 수에즈)
- **북유럽**: 부산→로테르담/함부르크 (약 28일)
- **지중해**: 부산→지중해 각항 (약 25일)

### 근해 (Short Sea)
- **중국**: 부산→상하이/닝보/칭다오 (2~3일)
- **일본**: 부산→도쿄/오사카 (2일)
- **동남아**: 부산→호치민/방콕/자카르타/마닐라 (5~7일)
- **인도/중동**: 부산→나바셰바/제벨알리 (약 18일)
