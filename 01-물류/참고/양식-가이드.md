# 물류 문서 양식 가이드 (Generative Image Source)

> 포워딩 물류 문서 양식에 대한 정보와 템플릿 가이드

## 주요 문서 양식

### 1. HBL (House Bill of Lading)
- **용도:** 포워더 발행 해상 선하증권
- **필수 기재 항목:**
  - Shipper / Consignee / Notify Party
  - Vessel & Voyage No.
  - Port of Loading / Discharge
  - Marks & Numbers / No. of Packages
  - Description of Goods
  - Gross Weight / Measurement (CBM)
  - Container No. / Seal No.
  - Freight Charge / Prepaid or Collect
  - Place and Date of Issue
- **참고:** 해상수출(LCL/FCL) 시 필수. 양식 이미지는 `assets/MIRAE_HBL_BLANK.pdf`

### 2. AWB (Air Waybill)
- **용도:** 항공 화물운송장 (IATA 표준)
- **필수 기재:**
  - Shipper / Consignee / Issuing Carrier's Agent
  - Airport of Departure / Destination
  - Flight & Date
  - Number of Pieces / Gross Weight
  - Rate Class / Chargeable Weight
  - Nature and Quantity of Goods
- **참고:** 항공수출 필수. 양식 이미지는 `assets/AWB_OUTBOUND_FORM.jpg`

### 3. DO (Delivery Order)
- **용도:** 수입화물 인도지시서
- **기재 항목:**
  - Consignee
  - Container No. / Seal No.
  - Vessel / Voyage
  - Cargo Description
  - Delivery Location
  - Customs Clearance Status
  - Issuance Date
- **참고:** 수입통관 후 CY에서 화물 인출 시 필요

### 4. DN (Debit Note) / CN (Credit Note)
- **용도:** 추가 비용 청구 / 차감
- **기재:**
  - Invoice No.
  - Service Description
  - Amount
  - Payment Terms

### 5. CI (Commercial Invoice) / PL (Packing List)
- **용도:** 통관용 상업 송장 / 포장 명세서
- **CI 기재:** HS Code, Unit Price, Total Amount, Terms (FOB/CIF)
- **PL 기재:** Gross/Net Weight, CBM, 각 Package 내용물

## 문서 생성 원칙

1. **빈 양식 절대 덮어쓰기 금지** — assets의 BLANK PDF는 원본 보존
2. **문서 유형별 템플릿 사용** — 표준 양식 기반 데이터 오버레이
3. **데이터 정확성** — HBL 번호, 날짜, 중량 등은 DB에서 실시간 조회
4. **언어** — HBL/AWB/Express는 영문전용, DO/DN은 한글허용
5. **폰트 크기** — 10pt 이하, 줄간격 3mm

## 기술 스택
- PDF 생성: Puppeteer + generate_exact_docs.mjs
- 이미지 오버레이: PDFDocument + Sharp
- OCR: Tesseract + pdftotext
