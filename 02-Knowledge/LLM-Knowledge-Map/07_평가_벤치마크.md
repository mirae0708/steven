## 2. SWE-Bench (가장 중요한 코딩 벤치마크)

### 개요
- 실제 GitHub **이슈 → PR 해결** 능력 측정
- 2,294개의 실제 Python 이슈
- **Verified (검증됨)** 와 **Unverified** 구분

### 2026년 현황

| 모델 | SWE-Bench Verified | 비고 |
|------|:-----------------:|------|
| Claude 4 Sonnet | ~45% | Anthropic |
| GPT-5 | ~50% | OpenAI |
| Codex CLI | ~38% | OpenAI |
| Qwen3-Coder | ~42% | Alibaba |
| DeepSeek-V3 | ~40% | DeepSeek |

### 한계
- **Python 전용** (다른 언어 미포함)
- **단일 파일 수정** 위주 (멀티 파일 부족)
- **이슈 선별 편향** (해결 가능한 이슈만 선정)

## 3. 평가 방법론 발전

### 🔹 LiveBench
- 고정된 정답이 아니라 **동적 평가**
- 오염(contamination) 방지
- 매월 새로운 문제로 갱신

### 🔹 Process Reward Model
- 최종 정답만 보지 않고 **추론 과정 평가**
- 단계별 정당성 검증
- RLHF의 Reward Model 발전 방향

## 4. 에이전트 평가

### 기존 벤치마크의 한계
- MMLU, GSM8K는 **단일 응답** 평가
- 에이전트는 **다단계 추론 + 도구 사용** 필요

### 새롭게 등장한 평가

| 평가 | 내용 | 특징 |
|------|------|------|
| **AgentBench** | 8개 에이전트 과제 | 멀티 도메인 |
| **WebArena** | 웹 브라우징 에이전트 | 실제 웹 환경 |
| **OSWorld** | OS 수준 에이전트 | 파일/앱 조작 |
| **GAIA** | 일반 AI 도우미 | 멀티 모달+도구 |
