# 클레임 방지 SOP (Standard Operating Procedure)

> 사전 예방이 최선의 클레임 관리입니다.

## 1. 수출 포장 가이드

### 일반 화물
- 골판지 상자: 2중 골판지 이상
- 팔레타이징: 4방향 진입 가능
- 래핑: 신축성 랩 3회 이상
- 라벨: 한글/영문 양면 부착

### 고위험 화물 (전자부품, 정밀기기, 유리제품)
- **방습 처리 필수:** Desiccant(실리카겔) 5g/m³ 이상
- **완충재:** 에어캡 + 발포폼 5cm 이상
- **컨테이너:** Ventilated 또는 Reefer(온도 민감품)
- **Cargo Survey 의무:** $10,000 이상

### 패션/전시 화물
- Priority Booking 계약
- D-7 예약, D-3 확정 체크
- Backup Booking 사전 확보
- 실시간 Flight Tracking

| 체크포인트 | 주기 | 담당 |

## 3. 클레임 예방 체크리스트

### 선적 전
- [ ] 포장 상태 사진 촬영
- [ ] 컨테이너 내부 청결/건조 상태 확인
- [ ] Seal Number 기록
- [ ] 적재 계획서(Illustration) 검토
- [ ] 보험 Coverage 확인

### 운송 중
- [ ] B/L or AWB 정보 정확성 재확인
- [ ] 화물 추적 정보 모니터링
- [ ] 경유지 환적 확인
- [ ] 통관 진행 상태 체크

### 도착 후
- [ ] Cargo Arrival Notice 발송
- [ ] 수하인에 도고/통관 안내
- [ ] 이상 발견 시 즉시 Incident Report
