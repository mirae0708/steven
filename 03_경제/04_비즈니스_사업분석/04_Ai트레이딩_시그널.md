# 📈 AI 트레이딩 시그널 구독 서비스

> 멀티 LLM 라운드테이블의 투자 분석 결과를 시그널 구독으로 상품화

## 💡 개요

현재 운영 중인 **멀티 LLM 라운드테이블** (전략가/분석가/비평가/혁신가 4개 AI 토론)의 결과를 정기 구독 시그널로 제공.

## 🏗️ 보유 기술

| 기술 | 상태 |
|:---|:---|
| 멀티 LLM 라운드테이블 | ✅ 4개 LLM 토론 → 투표 → 결론 |
| FOMC 분석 | ✅ 주간 시장 프리뷰 |
| 일일 시장 브리핑 | ✅ Telegram 발송 |
| 주식/지수 실시간 데이터 | ✅ Yahoo Finance API |
| 포트폴리오 모니터링 | ✅ ±3% 알림 |

## 🎯 서비스 구성

### 무료 (기본)
- 일일 시장 요약 (KOSPI/KOSDAQ/미국)
- 주요 뉴스 헤드라인

### 유료 (월 5~20만원)
- **멀티 LLM 종목 분석 리포트** (주 2회)
- **매수/매도 시그널** (알림)
- **포트폴리오 리스크 분석**
- **FOMC 프리뷰/리뷰**

## 📈 사업성

| 항목 | 내용 |
|:---|:---|
| **타겟** | 개인 투자자 1,000명 목표 |
| **경쟁** | 네이버 카페/텔레그램 시그널 (AI 아닌 사람이 운영) |
| **차별점** | 4개 AI 토론, 감정 배제, 데이터 기반 |
| **월 ARPU** | 5~20만원 |
| **월 예상 매출** | 5,000만~2억 (1,000명 기준) |

## ⚠️ 리스크

| 리스크 | 대응 |
|:---|:---|
| 투자 손실 법적 리스크 | "참고용" 면책 문구 필수 |
| AI 환각/오판 | 4개 LLM 크로스체크로 최소화 |
| 고객 유지율 | 실제 수익률 인증 필요 |
