## 6. 중요 발견: HBL 컨테이너 정보 구조적 문제

document-generator.cjs의 HBL 생성 로직 (94~106줄):
```javascript
let containers = [];
try { containers = order.rich_payload ? JSON.parse(order.rich_payload).containers || [] : []; } catch(e) {}
containers.forEach((c, idx) => {
    if (idx < 8) {
        fields.push({ x: 60, y: 530 + idx * 20, text: c.container_no || '', fontSize: 8 });
        fields.push({ x: 220, y: 530 + idx * 20, text: c.seal_no || '', fontSize: 8 });
        fields.push({ x: 350, y: 530 + idx * 20, text: c.size_type || '', fontSize: 8 });
    }
});
```

**문제점**:
1. `rich_payload`는 JSON 텍스트 컬럼 — orders 테이블에 컨테이너 정보가 정규화되지 않음
2. `containers[]`가 없으면 0개 출력 (빈 HBL)
3. orders 테이블에 `container_no`, `seal_no`, `size_type` 컬럼이 별도로 있지만 generateHBL이 사용 안 함
4. 테스트 데이터 4건 모두 rich_payload가 `{}` 이거나 NULL — 컨테이너 정보 없음
