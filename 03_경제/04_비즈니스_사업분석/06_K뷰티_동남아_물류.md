## 🎯 서비스 구성

### Phase 1: 물류 대행
- 한국 → 동남아 항공/해상 특송
- 관세/통관 대행
- 현지 라스트마일 배송

### Phase 2: 풀필먼트
- 한국 내 집품/포장
- 동남아 현지 창고 보관
- 실시간 재고/주문 관리 시스템

### Phase 3: 통합
- Shopee/Lazada/TikTok Shop API 연동
- 주문 → 물류 → 배송 → CS 자동화
