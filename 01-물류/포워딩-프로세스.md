# 📋 포워딩 업무 흐름도 (Freight Forwarding Workflow)

> **미래국제물류 기준** — 해상/항공/특송 전체 프로세스 통합

## 1️⃣ Pickup (화물 수거)

| 단계 | 해상 (Ocean) | 항공 (Air) | 특송 (CXR) |
|:-----|:-------------|:-----------|:-----------|
| **요청** | Trucking Order 발행 | Cargo Pickup Request | 특송사 API Booking |
| **운송** | Container Truck (FCL) / 지입차 (LCL) | Cargo Van / 소형트럭 | 특송사 Van |
| **반입처** | CY (Container Yard) or CFS | Air CFS (ICN CFS) | 특송사 Hub |
| **문서** | Picking List, Cargo Manifest | Cargo Manifest | Shipping Label |

## 2️⃣ Export (수출 통관 및 선적)

| 단계 | 설명 |
|:-----|:------|
| **통관** | 수출 신고 (UNI-PASS EDI) |
| **보안 검색** | 항공: X-Ray 검사 / 해상: VGM 제출 |
| **적재** | CY 반입 → Vessel Loading / CFS Build-up |
| **B/L 발행** | SI 제출 → HBL → MBL 순서 |
| **사전 통보** | Pre-alert → Consignee / Agent |

## 3️⃣ Main Carriage (본 운송)

| 모드 | 운송 수단 | Transit Time | Tracking |
|:-----|:----------|:-------------|:---------|
| **해상 FCL** | Container Vessel | 2~28일 | Container # |
| **해상 LCL** | Container Vessel (CFS) | 2~28일 | HBL # |
| **항공** | Cargo Aircraft / Belly | 1~3일 | AWB # |
| **특송** | Cargo Aircraft | 1~2일 | Track # |

## 4️⃣ Import (수입 통관)

| 단계 | 설명 |
|:-----|:------|
| **도착 통보** | Arrival Notice 발행 (ETA 기준) |
| **DO 교환** | B/L 원본 or Telex Release → D/O 수령 |
| **통관** | 수입 신고 + 관세/부가세 납부 |
| **검사** | 서류검사 / 실물검사 (선별) |
| **반출** | CFS/CY에서 화물 인수 |

## 5️⃣ Delivery (최종 배송)

| 모드 | 배송 방식 |
|:-----|:----------|
| **CY (FCL)** | Consignee 자체 Trucking or 지정 Trucker |
| **CFS (LCL)** | CFS에서 Tailgate Pickup |
| **항공** | Air CFS에서 Tailgate or Door Delivery |
| **특송** | 특송사 Door-to-Door Delivery |
