# 텔레그램 명령어 모음

> Hermes Agent가 텔레그램에서 인식하는 명령어 패턴
> 자연어 기반 — 정해진 명령어가 없어도 문맥 이해 가능

## 📊 시장/트레이딩

| 명령 예시 | 동작 | 비고 |
|:---------|:------|:-----|
| `장 분석해줘` | 시장 분석 리포트 생성 | KOSPI/KOSDAQ/환율/WTI |
| `014950 분석` | 개별 종목 분석 | 종목코드 입력 가능 |
| `포트폴리오 현황` | 현재 포트폴리오 손익 | 보유 종목 + 현금 |
| `뉴스 확인` | 오늘의 시장 뉴스 | 네이버 메인뉴스 파싱 |
| `오늘 리포트` | 일간 분석 리포트 | 장 전/중/후 |
| `시장 스캔` | 전 종목 스캔 | --scan 모드 |
| `백테스트 해줘` | 전략 백테스트 실행 | --backtest 모드 |
| `섹터 분석` | 업종별 분석 | --sector 모드 |

## 💾 지식 저장/검색

| 명령 예시 | 동작 | 비고 |
|:---------|:------|:-----|
| `Obsidian에 저장해` | 현재 내용을 Vault에 저장 | 파일 기반 통신 |
| `이거 Context에 올려줘` | Members→Context 승격 요청 | PR 초안 생성 |
| `Wiki에서 찾아줘` | Obsidian Vault 검색 | Brain Sync 활용 |
| `기억해둬` | 메모리 저장 | 영구 기억 |

## 🏢 물류/업무

| 명령 예시 | 동작 | 비고 |
|:---------|:------|:-----|
| `견적 내줘` | Freight Quote 실행 | 해상/항공 자동 견적 |
| `인보이스 처리` | Invoice Auto 실행 | 인보이스 자동 입력 |
| `ERP 접속` | MRCloud ERP 브라우저 | SYS9005/SEA1002 등 |
| `메일 열어줘` | 가상오피스 메일 시스템 | EMAIL_ENABLED=true 필요 |

## 🔧 시스템/관리

| 명령 예시 | 동작 | 비고 |
|:---------|:------|:-----|
| `상태 확인` | 시스템 상태 점검 | tmux/서비스/WSL |
| `크론 현황` | cron 작업 목록 | 18개 작업 |
| `로그 봐줘` | 최근 로그 조회 | |
| `업데이트 해줘` | 자기 진화 실행 | Auto-Evolution |
| `그만` / `그만해` | **즉시 모든 작업 중단** | 긴급 중단 명령 |

## ⚡ 단축키/특수

| 명령 | 동작 |
|:-----|:------|
| `❗️` | 긴급 — 포트폴리오 ±3% 체크 후 보고 |
| `📸` | 현재 상황 스크린샷 (Playwright) |
| `뭐 하고 있어?` | 현재 실행 중인 작업 보고 |

## 📝 주의사항

- **호칭**: 텔레그램에서는 "대장님"으로 응답
- **멘션 불필요**: `require_mention:false` — 멘션 없이도 응답
- **TTS 자동 첨부**: 텍스트 메시지 + 음성 파일 함께 전송
- **자연어 OK**: 정해진 명령어 없어도 문맥으로 이해
- **텔레그램 채널**: TELEGRAM_HOME_CHANNEL 설정 완료
