## 📊 사업성 평가 기준

```
사업성 = (시장규모 × 수요강도 × 진입장벽) / (초기투자 × 운영복잡성)
```

| 항목 | 측정 기준 |
|:---|:---|
| 시장규모 | TAM 100억↑ / 10억↑ / 1억↑ |
| 수요강도 | 기존 문의/니즈 존재 여부 |
| 진입장벽 | 특허/라이선스/네트워크 필요도 |
| 초기투자 | 개발인력/인프라 비용 |
| 운영복잡성 | 유지보수 난이도 |
