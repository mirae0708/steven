# 📄 인보이스 OCR → ERP 자동입력 B2B 서비스

> PDF/Excel 인보이스 한 장 넣으면 → AI가 읽고 → ERP에 자동 입력

## 💡 개요

`invoice_auto`의 AI 파싱 엔진(InvoiceParser)만 떼어내서 **OCR B2B API 서비스**로 상품화.

현재 우리 파이프라인:
```
PDF/Excel → GLM-4.7-Flash → DeepSeek → 로컬Regex → 정형 JSON
```

## 🏗️ 핵심 경쟁력

| 항목 | 우리 | 경쟁 OCR 서비스 |
|:---|:---|:---|
| **AI 정확도** | GLM Flash(무료)+DeepSeek 이중 파싱 | 단일 AI or 규칙기반 |
| **ERP 연동** | ✅ 직접 시스템 입력까지 | ❌ OCR 결과만 제공 |
| **가격** | 무료 AI 모델 활용 → 초저가 | 건당 500~2000원 |
| **다국어** | 한/중/영 대응 | 영어 위주 |
| **템플릿 불필요** | AI가 알아서 파싱 | 템플릿 등록 필요 |

## 🎯 타겟

1. **물류 포워딩사** — 매일 수백장 인보이스 처리
2. **무역 회사** — 수출입 서류 자동화
3. **ERP 회계 프로그램** — API 연동 파트너
